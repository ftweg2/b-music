## UI 实测

通过浏览器操作隔离生产构建：普通页面同源搜索；顶部点选 2/5 页、输入 4 后回车跳页；第 1/2 页分别 20/19 条且交集为 0；返回第 1 页标题和顺序不变；390px 手机视口无横向溢出；手机表单新建歌单成功；歌单播放及刷新后队列恢复；设置页显示更换账号/退出登录入口。测试后恢复浏览器视口。

UI 实测发现并修复了 Next 规范化 localhost 与浏览器实际 Host 不一致导致 127.0.0.1 请求被误报跨站的问题；外部来源和伪造 forwarded host 仍拒绝。允许的 WebView 登录不再被第二套来源校验拦截。播放就绪通知不再声称暂停/结束时仍“正在播放”。

最终构建和 107 项 App 测试再次通过；正式 kernel 健康，active_jobs/profile_locks/profile_readers 均为 0，登录资料保留。临时 3100/8100 服务和测试容器已停止/移除，仅删除可重新生成的容器内测试音频；JSON 报告、临时 App 元数据和日志保留。未关闭或清理正式服务的音乐库。

## 范围与限制

- 默认仍是受信任的本地单用户音乐库，不是带多租户鉴权的公网服务；手机跨网络连接需正确 Base URL 和鉴权 HTTPS 网关，未自动开放网络端口。
- 真实 Bilibili 网络、下架、视频访问权限和风控仍可能使搜索/播放失败；不会绕过权限或将失败页悄悄替换成本地结果。
- 只做了有界的重复、并发、异常与恢复验收，不能证明任意未来输入永远零 bug。真实登录/真实曲目采用有限冒烟测试；登录取消/退出等破坏性验收仅在隔离环境。
