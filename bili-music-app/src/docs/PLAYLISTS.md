# 歌单与关注优先

## 搜索

已关注 UP 的匹配结果优先，不计算分数。在线搜索只对当前来源返回页分组，不额外抓取其他页面；同组保持来源顺序。本地搜索先按当前用户的关注状态分组，再按最近发现时间排序并分页。

## 歌单功能

- 入口：桌面侧栏、手机底栏的「我的歌单」。
- 创建歌单、编辑名称与简介、删除歌单。
- 在搜索、收藏、已准备曲目或详情中选择「加入歌单」。
- 可从加入歌单弹窗直接创建歌单并添加当前曲目；创建和添加是一个事务。
- 同一曲目可放入多个歌单，同一歌单不重复保存相同 BV。
- 上移／下移调整顺序，移除曲目不影响收藏或其他歌单。
- 整单播放、随机播放和加入播放队列。排队只保存元数据，只有实际播放到某首歌时才准备音频。

每个用户最多 100 个歌单，每个歌单最多 200 首。名称 1–80 字符，简介最多 500 字符。当前没有公开分享、云同步或整单批量下载。

## 存储

新增 playlists 和 playlist_items 表。歌单按 App owner 隔离；曲目以 BV 去重，并保存白名单元数据快照。候选缓存删除时只清空 candidate_id，重新读取歌单会从快照恢复曲目，歌单条目 ID 和顺序不变。

不保存音频文件、签名媒体 URL、Cookie 或内核登录数据。删除歌单只删除歌单及其条目，不修改收藏、关注、其他歌单和内核文件。
